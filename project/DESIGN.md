# 3D 太阳系实验设计（一页纸）

## 1. 实验目标

使用固定管线 OpenGL 构建一个可交互的 3D 太阳系，重点演示：**光照模型、材质、纹理、透明混合、雾、动画与相机交互**。目标不是天文仿真，而是让每个图形学技术都能在画面上被明确指出来。

## 2. 技术路线与约束

- freeglut + 传统固定管线：`glMaterial*`、`glLight*`、`gluSphere`、`glBlendFunc`、`glFog*`
- C++11 / CMake / MinGW；构建用 `build.cmd`，运行用 `Build-and-Run.cmd`
- 保留 `--smoke-test` 自动自检：退出码 0 且输出 `RENDER_TEST: PASS`
- 不引入 GLAD / GLEW / GLSL，不依赖外部模型文件（`.obj` 等）
- 纹理优先读取 `project/assets/` 下的 BMP；缺失时用程序化纹理兜底

## 3. 场景内容

- 太阳（自发光）、8 颗行星、月球、土星环、行星轨道线、星空背景
- 尺寸与轨道距离采用**视觉缩放**（真实比例无法同屏显示），公转周期按相对快慢缩放
- 行星材质各不相同：岩石类高粗糙、气态巨行星弱高光、地球有纹理与大气层

## 4. 技术点与验收标准

| # | 技术点 | 实现手段 | 画面上的验收现象 |
|---|---|---|---|
| 1 | 透视投影与深度测试 | `gluPerspective` + `GLUT_DEPTH` + `glEnable(GL_DEPTH_TEST)` | 近处行星正确遮挡远处行星与轨道 |
| 2 | 层级变换 | `glPushMatrix` / `glPopMatrix` | 月球绕地球转，同时地球绕太阳转 |
| 3 | 光照模型 | `GL_LIGHT0` 点光源位于太阳 + 全局环境光 | 行星有明暗交界线，背光面不是纯黑 |
| 4 | 材质 | `glMaterialfv` 的 ambient/diffuse/specular/shininess | 不同行星高光强弱可区分 |
| 5 | 纹理 | BMP 加载 + `gluQuadricTexture` + mipmap | 地球可见大陆/海洋，远处不闪烁 |
| 6 | 透明混合 | `GL_BLEND` + 远到近排序绘制 | 土星环与大气层半透明，无黑边 |
| 7 | 雾 | `GL_FOG` | 远处行星逐渐融入背景色 |
| 8 | 自发光 | `GL_EMISSION` | 太阳不受场景光照影响，始终明亮 |
| 9 | 动画 | `glutTimerFunc` + 时间步长 | 暂停/倍速下运动平滑且可复现 |
| 10 | 交互 | 鼠标 + 键盘 | 相机环绕、缩放、模式切换可操作 |

## 5. 里程碑（每阶段独立可运行）

- **M0 3D 骨架**：透视投影、深度测试、球坐标轨道相机；用线框球体画出太阳与地球
  - 验收：球体有正确遮挡关系，鼠标拖动可环绕观察
- **M1 运动系统**：公转/自转、层级变换、时间倍速与暂停
  - 验收：月球-地球-太阳三级运动正确，加速不跳帧
- **M2 光照**：启用光照，太阳位置设为 `GL_LIGHT0`，配置各行星材质
  - 验收：出现昼夜明暗面，不同行星反光特性不同
- **M3 纹理**：BMP 纹理加载、纹理坐标、mipmap、程序化兜底纹理
  - 验收：地球、木星、土星表面纹理正确且无拉伸
- **M4 渲染效果**：土星环、大气透明、雾、太阳光晕、星空
  - 验收：透明物体排序正确，远景有空间纵深感
- **M5 交互与打磨**：完整键鼠控制、HUD 提示、性能与细节优化
  - 验收：所有交互稳定，帧率流畅，`--smoke-test` 通过

## 6. 交互设计

| 输入 | 功能 |
|---|---|
| 鼠标左键拖动 | 环绕相机（方位角/俯仰角） |
| 滚轮 | 拉近/拉远 |
| 空格 | 暂停/继续 |
| `+` / `-` | 时间加速/减速 |
| `L` | 切换光照 |
| `W` | 线框模式 |
| `R` | 重置视角与时间 |
| `Esc` | 退出 |

## 7. 明确不做

阴影、PBR、HDR、后处理（泛光/景深）、模型导入、碰撞检测、真实天文精度、行星贴图的高精度还原。

## 8. 风险与对策

- **透明排序**：先画全部不透明物体，再按相机距离从远到近画透明物体；土星环双面渲染
- **法线问题**：非均匀缩放后启用 `GL_NORMALIZE`，否则光照会变暗或错位
- **深度冲突**：土星环与球体之间使用 `glPolygonOffset`，避免闪烁
- **性能**：球体细分控制在 32×32，星空用 `GL_POINTS`，避免每帧重建几何
