OpenGL 固定管线 API 速查

freeglut 3.8.0 · OpenGL 2.1 固定管线（opengl32）· GLU 1.3（glu32）· MinGW-w64 / C++11

本地 freeglut 完整 API（api.md） Microsoft OpenGL Reference Microsoft GLU Functions Khronos OpenGL 2.1 Refpages freeglut API（在线） Red Book（固定管线）

先分清版本：你的驱动报告 OpenGL 4.6，但项目代码使用的是 OpenGL 2.1 固定管线 + GLU， 不是 4.x 核心管线。不要照 docs.gl 或现代教程写 shader / VAO / GLAD，那些和本实验不兼容。 函数签名以本机头文件为准：tools/mingw64/x86_64-w64-mingw32/include/GL/gl.h、glu.h； freeglut 头文件在 project/third_party/freeglut/include/GL/。

矩阵 / 相机

glMatrixModeGL

void glMatrixMode(GLenum mode);

选择当前矩阵栈：GL_MODELVIEW（模型+视图）、GL_PROJECTION（投影）、GL_TEXTURE（纹理）。

选错栈是初学者最常见的“画不出来”原因之一。

MS 文档

glLoadIdentityGL

void glLoadIdentity(void);

把当前矩阵置为单位阵。每帧 display() 开头重置模型视图矩阵，避免变换累积。

MS 文档

glPushMatrix / glPopMatrixGL

void glPushMatrix(void);
void glPopMatrix(void);

矩阵栈压栈/弹栈。做层级变换（太阳 → 地球 → 月球）时，用它们保存父级坐标系，画完子物体后恢复。

这也是“齐次坐标 + 4×4 矩阵统一表示”的固定管线体现。

MS 文档

glTranslatefGL

void glTranslatef(GLfloat x, GLfloat y, GLfloat z);

在当前矩阵上叠加平移。注意：平移不是线性变换，它会把原点挪走。

MS 文档

glRotatefGL

void glRotatef(GLfloat angle, GLfloat x, GLfloat y, GLfloat z);

绕轴 (x,y,z) 旋转 angle 度。公转/自转都靠它，顺序不同结果不同。

角度制，不是弧度；旋转是线性变换，原点保持不动。

MS 文档

glViewportGL

设置渲染视口（屏幕上的像素矩形），通常在 reshape() 里调用。

MS 文档

gluLookAtGLU

void gluLookAt(GLdouble eyeX, GLdouble eyeY, GLdouble eyeZ,
               GLdouble centerX, GLdouble centerY, GLdouble centerZ,
               GLdouble upX, GLdouble upY, GLdouble upZ);

定义视图矩阵：把 eye 放到原点、让 center 落在 -z 轴。相机运动就是改 eye，物体世界坐标不动。

up 通常取 (0,1,0)；up 不能与 eye→center 的视线平行，否则矩阵退化。

MS 文档

gluPerspectiveGLU

建立透视投影矩阵。fovy 是垂直视场角（度），aspect = 宽/高，zNear/zFar 是近远裁剪面。

必须放在 glMatrixMode(GL_PROJECTION) 之后；本项目用 45°、0.1、100。
